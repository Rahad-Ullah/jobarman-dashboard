# Jobarman Dashboard

## Getting Started

### First, clone the repository:
```bash
git clone https://github.com/Rahad-Ullah/jobarman-dashboard.git
```

### Second, install packages:
```bash
npm install
# or
yarn install
```

### Create the `.env.local` file and set environment variables following these:

```javascript
NEXT_PUBLIC_SERVER_URL="https://shariful5001.binarybards.online"
NEXT_PUBLIC_BASE_URL="https://shariful5001.binarybards.online/api/v1"
```

### Finally, run the development server:

```bash
npm run dev
# or
yarn dev
```

### Happy Coding 🚀
